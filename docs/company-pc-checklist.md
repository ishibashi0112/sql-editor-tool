# 会社 PC での確認のチェックリスト（0.13.0）

`sql-editor-tool-0.13.0.vsix` を会社 PC の VS Code に入れて確かめるためのものです。会社 PC で確認済みなのは 0.1.0（接続・表示・絞り込み・中止）と 0.2.0（画面ですぐ絞り込む）、0.7.2 の Oracle の接続（Thick モード）、0.8.1 の論理名（G）と `.sql` の実行（H）の主なところです。結果は `docs/handover.md` の §14 に記録します。

0.9.0 では、レポートの機能をなくし、`.sql` の実行（Ctrl+Enter）に一本化しました（D-43）。`.sql` に `:名前`（SQL Server では BI ツールに登録する SQL の `@変数` も）があれば、結果のタブの上に入力欄が出ます。入力欄の設定・接続・入れた値は VS Code の中に覚え、`.sql` は書き換えません。別の PC へは「設定を書き出す／読み込む」で引き継ぎます（D-44）。**まず R（入力欄のある .sql の実行）と T（設定の引き継ぎ）を見てください**（ほかは時間があれば）。

0.8 までにレポートとして作った `.sql`（先頭に `/* @report … */` のコメントがあるもの）は、そのまま Ctrl+Enter で使えます。サイドバーの「レポート」はなくなりました。

0.13.0 では、A5:SQL Mk-2 の「SQL の生成」をまねて、テーブルから SELECT 文を作る機能を足しました（Q、D-49）。テーブル検索・接続のツリーの表を右クリック →「SQL を生成…」で、新しいエディタに開きます。**0.13.0 では Q を見てください。**

0.12.1 では、「表でコピー」を Excel に貼ったときの崩れを直し、条件の入力欄に列の一覧を足しました（X-11・X-16）。**0.12.1 では X-11 と X-16 を見てください。**

0.12.0 では、差分カメラに、Excel に貼れる「表でコピー」と「Excel で保存」、比べた記録、条件の入力欄の列の候補を足しました（X-11〜X-15、D-48）。**0.12.0 では X-11〜X-15 を先に見てください。**

0.11.0 では、差分カメラを足しました（X、D-47）。**0.11.0 では X を先に見てください。** 検証用の DB（本番ではない DB）で、自分の画面を操作して試してください。

0.10.0 では、`.sql` の整形を足しました（S、D-45）。Prettier SQL VSCode で整形すると `:開始` が `BETWEEN: 開始` のように分かれて入力欄にならなかったので、`:名前`・`@名前` を分けずに整形します。**0.10.0 では S を先に見てください。**

ホスト名・IP・DB 名・スキーマ名・テーブル名・列名・業務データは伏せてください（「日付の列 A」のように置き換える）。
