### D-2 入力欄の種類の推定（0.5.0、O-15）

次の形の SQL を 1 本作ってください（実際の列に置き換える）。

```sql
SELECT *
FROM <テーブル>
WHERE <yyyymmdd の列> >= :開始日
  AND <yyyymmdd の列> <= :終了日
  AND (:コード IS NULL OR <文字列のコードの列> = :コード)
  AND <数値の列> >= :最小数量
  AND <datetime の列> >= :登録日
```

| No | 優先 | 操作 | 期待する結果 | 結果 |
|---|---|---|---|---|
| D-2-1 | ★★ | 開いて「⚙ 入力欄」を開く | 開始日・終了日＝日付（yyyymmdd の文字列の列と比べる）、コード＝文字列、最小数量＝数値、登録日＝日付（日付型の列と比べる）。どれにも「（推定）」が付く | |
| D-2-2 | ★ | `AND <列> = COALESCE(:別名, <列>)` を 1 行足す | ほかの欄の種類が崩れない（別名は文字列） | |
| D-2-3 | ★ | 「⚙ 入力欄」で保存 → `.sql` の先頭のコメントを見る | 推定した種類が書かれ、「（推定）」は消える | |

期待と違った欄があれば、その行の形と列の型を控えてください。

| H-3 | ★★ | `;` で区切った文が複数あるファイルで、2 つ目の文の中で Ctrl+Enter／`;` を書かずに SELECT を並べたファイルで同じことをする | その文だけを実行する | |
| H-4 | ★ | 2 つの文を範囲で選んで Ctrl+Enter | タブが 2 つ（「ファイル名 (1)」「(2)」）できる | |
| H-5 | ★★ | `:名前` のある文を実行 | 結果のパネルに入力欄が出て、カーソルがそこに移る。値を入れて Enter で実行。もう一度 Ctrl+Enter すると、前の値ですぐ実行する | |
| H-6 | ★ | 行の多い表で実行（上限を超える） | 「上限で打ち切りました」の案内と「今の絞り込みで DB から取り直す」 | |

| H-8 | ★ | 別のファイルで実行した後、エディタで元のファイルに戻る | 元のファイルの結果のタブが前に出る | |
